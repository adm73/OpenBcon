# Contributing

Thank you for helping improve Bconomics.

## Development

1. Fork the repository and create a focused branch.
2. Run `npm install`.
3. Run `npm run db:setup` when working on persisted features.
4. Make the smallest coherent change.
5. Add a migration instead of editing an applied migration.
6. Run `npm run check`.
7. Open a pull request describing the behavior and verification.
